Symmetrical Sequential Evaluation. Rather than evaluating translation solely as text-to-text token matching or generic stock photos, AfriVL-Bench tests whether multimodal LLMs can identify authentic, culturally grounded visual referents approved by native speakers:
  • Human Ground Truth: Native speakers review candidate photos grounded in target countries (Ghana, Nigeria, Kenya, Tanzania, Ethiopia, Senegal, Gambia, South Africa), confirming whether an image accurately depicts the local word.
  • Procedural Fairness: If a human accepted the 1st photo, the model receives a binary Yes/No prompt on that image alone. If the human accepted candidate k (after rejecting earlier photos), the model is given strictly those k candidates to choose from.
  • Evaluation Key: Model performance is scored directly against native-speaker consensus.
